# Prova: extrair-evidencia (avaliador)

Lote de duas Entradas da CLB cajuína (CL-0001, Termo TE-0002): `{raiz}/entrada/EN-1369.json` e `{raiz}/entrada/EN-1544.json`. O texto lido de cada fonte está em `{raiz}/fonte/EN-1369.txt` e `{raiz}/fonte/EN-1544.txt`: é a fonte reduzida às janelas de citação já guardadas, separadas por `[…]`.

Faça o que a habilidade extrair-evidencia pede (triagem por valências pela escala de `esquemas/valores-provisorios.json`, marca de aviso, saúde ou política, extração com leitura fiel, voz, lugares ditos pela fonte). Para cada Evidência, escolha o texto exato na fonte e rode
`.venv/Scripts/python.exe scripts/localizar_trecho.py localizar --fonte {raiz}/fonte/<EN>.txt --trecho "<texto exato>" --saida {saida}/trechos/<EN>-<n>.json`
(n = 1, 2, 3...). O Trecho vale pelo arquivo que o script grava, nunca pelo texto que você escreve.

Devolva `{saida}/saida-avaliador.json` neste formato (o do lote do bloco 7):
```
{"lote": "teste", "entradas": [
  {"entrada": "EN-nnnn", "estado": "aceito" | "quarentena",
   "valencias": {"lastro": 0-2, "trecho_localizado": 0-2, "voz": 0-2, "versao_regra": "valencias-0.1", "criterio_em_falta": []},
   "sustenta_aviso_saude_politica": true | false,
   "fonte": {"titulo": "...", "tipo_documento": "...", "ano": "...", "instituicao": "...", "tipo_evidencia": "...", "perspectiva": "...", "deriva_de": "..."},
   "evidencias": [
     {"arquivo_trecho": "{saida}/trechos/EN-nnnn-1.json", "chave": "<tema>|<valor curto>", "atributo": "...", "valor": "...",
      "periodo_referido": "...", "sentido": "a favor" | "divergente", "voz": {"tipo": "...", "papel": "..."},
      "lugares": {"pratica": null | "Município, UF", "publicacao": ..., "pesquisa": ...},
      "criterio_pratica_cultural": null | "...", "sustenta_aviso_saude_politica": true | false}]}]}
```
Validação (tem de passar): `.venv/Scripts/python.exe scripts/gravar_extracao.py {saida}/saida-avaliador.json --execucao EX-0000 --raiz {raiz} --simular --manifestos {saida}`.
