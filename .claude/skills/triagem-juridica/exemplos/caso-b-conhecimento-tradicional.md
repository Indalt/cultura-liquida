# Caso B — conhecimento tradicional de origem identificável (16-J; plano, item 7)

**Origem:** plano, item 7 ("Se for, a origem é identificável? [...] Identificável: o acesso depende de consentimento prévio informado [...]. Sem consentimento: Falta") e 16-J, item 4. Caso construído, sem pessoa real.

**Entrada (ID `T-0001`, trecho de etnografia publicada):** o trecho descreve, com a fala de uma praticante, o modo de fazer de uma bebida fermentada de mandioca, atribuindo-o a uma comunidade indígena nomeada no texto, com o uso de uma folha nativa para iniciar a fermentação.

**Respostas às perguntas fixas:**
1. Direito autoral: o modo de fazer é livre (art. 8º, I); o texto do pesquisador só por citação curta com autor e origem (art. 46, III) → sem dúvida.
2. **Conhecimento tradicional: sim** (comunidade indígena, uso de planta nativa e de fermentação, que envolve espécies microbianas, art. 2º, I) e **origem identificável** (comunidade nomeada). Sem consentimento → **Falta**.
3. Restrição por costume: não informada no trecho → registrar no campo restrição como "não informada".
4. Dados pessoais: a praticante é citada pelo pesquisador; no projeto, só papel ("quem fala no trecho") e ID opaco.
5–8: não se aplica no degrau 1.
